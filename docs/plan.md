# ProofCV 设计记录

目标：给求职者一个可直接填写和导出的简历工作台。AI 只基于用户提供的事实生成摘要、技能、经历与项目要点；每次建议都要由用户确认后写入简历。

实现：零前端依赖的静态网页负责结构化编辑、自动本地保存、实时预览、岗位关键词检查与 PDF/Markdown/JSON 导出。Node 22 原生 HTTP 服务负责同源静态文件和 AI 代理；密钥仅从环境变量读取。公开静态演示保留编辑与导出，本地启动服务并配置密钥后启用 AI。

核心风险：模型仍可能生成不实内容，所以界面标明需核实，AI 结果绝不自动覆盖原文。岗位匹配只是关键词提示，不宣称能预测 ATS 结果。浏览器 localStorage 在共享电脑上不适合保存敏感简历，提供清空功能。

验收：编辑与预览同步；刷新后本地恢复；导出内容正确；AI 缺少密钥时明确报错；服务端拒绝超大请求并校验 AI JSON；测试覆盖编辑数据、导出、分析和代理。
